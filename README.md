## Задания варианта

Средняя сложность:

- №1 — окно с кнопкой «Привет»
- №6 — прогрессбар
- №9 — цветная панель (меняет цвет по кнопке)

Повышенная сложность:

- №2 — рисование фигур мышью
- №9 — приложение PyQt с таблицей

## Зависимости

```bash
pip install -r requirements.txt
```

Tkinter входит в стандартную библиотеку Python.  
PyQt5 нужен только для задания №9 повышенной сложности.

## Запуск

Меню со всеми заданиями:

```bash
python -m lab5
```

По отдельности:

```bash
python -m lab5.hello_button      # №1
python -m lab5.progress_bar      # №6
python -m lab5.color_panel       # №9
python -m lab5.draw_shapes       # №2↑
python -m lab5.pyqt_table        # №9↑
```

## Структура

```text
lab5/
```
